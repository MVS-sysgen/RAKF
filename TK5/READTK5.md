# Install RAKF 2.0.0. on an MVS 3.8J Turnkey 5 system.

The **trkf200.zip** file in this directory is meant for an install on a TK5 system.
This file will also be published on www.cbttape.org with filename file850.

**trkf200.zip** is present in MVS Turnkey 5, Update 6 as data set **USERMOD.TRKF200**.

## Install instructions.

After unzipping and upload to a MVS system, RECEIVE this xmi file with the NJE38 RECEIVE 
command.
Call the received PDS, **USEMOD.TRKF200**.

Read member **$$$$READ** for the installation instructions.
